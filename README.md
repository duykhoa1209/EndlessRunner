# 🏃 Endless Runner

**Game endless runner 3D** - chạy, nhảy, né chướng ngại vật, lưu điểm cao nhất.

## 🎮 Cách chơi
| Phím | Hành động |
|------|-----------|
| `Space` | Nhảy |
| `A / ←` | Sang trái |
| `D / →` | Sang phải |
| `ESC` | Pause |

## ✨ Tính năng
- 🧱 Spawn chướng ngại vật vô hạn (Object Pooling)
- 📈 Tăng độ khó dần theo thời gian
- 🏆 Lưu điểm cao nhất (PlayerPrefs)
- 🎨 Main Menu, Pause, Game Over UI
- 🔊 Âm thanh (nhạc nền, jump, hit, game over)
- 🔄 Chơi lại không cần restart

## 🛠️ Công nghệ
- Unity 6
- C#
- TextMeshPro
- Object Pooling
